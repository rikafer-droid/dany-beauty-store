# 💄 Dani Beauty Store — Landing Page

Landing page estática desenvolvida para a **Dani Beauty Store**, uma loja de presentes, perfumes e cosméticos localizada em São Paulo.

O projeto foi desenvolvido com foco em **apresentação da marca, experiência mobile e conversão de visitantes em contatos e vendas**, direcionando o público para WhatsApp, Instagram, Natura e catálogo de produtos.

---

## ✨ Sobre o projeto

A Dani Beauty Store possui presença ativa nas redes sociais e boa reputação no Google.

A landing page foi criada para funcionar como uma **central digital da marca**, reunindo em um único endereço os principais canais de contato e compra.

## 🎯 Objetivo

O principal objetivo do projeto é facilitar o caminho entre o visitante e a Dani Beauty Store.

### Fluxo pensado para o usuário:

```text
📱 Instagram
      ↓
🌐 Landing Page
      ↓
💄 Conhece a marca
      ↓
🎁 Conhece as categorias
      ↓
⭐ Confia na marca
      ↓
🛍️ Escolhe onde comprar
      ↓
💬 WhatsApp / Natura / Catálogo
```

A página não possui checkout ou sistema de e-commerce próprio.

Ela funciona como uma **landing page comercial**, direcionando o usuário para os canais oficiais da marca.
